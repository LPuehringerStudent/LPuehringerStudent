### Projects

**[auspex](https://github.com/auspex-lang/auspex)** · C
A procedural database scripting language and SQL engine. It has C-like syntax with inline SQL and compiles to bytecode for a custom stack VM, which runs on a built-in B-tree storage engine or on SQLite. I lead the project. CI runs on Linux, macOS and Windows.

**[Tripwire](https://github.com/LPuehringerStudent/tripwire)** · Rust, TypeScript
A training simulator for phishing emails and scam phone calls. Gemma 4 writes the scenarios and plays the caller in live voice calls through ElevenLabs, and a Rust (Axum) backend sits in between. We built it in one day and won 1st overall at the MLH × YAIL Hacktoberfest HackDay 2026. [Live demo](https://hacktober.lpuehringer.dev)

**[RedQuorum](https://github.com/LPuehringerStudent/RedQuorum)** · Python, Angular
A multi-agent AI security scanner. Several specialist agents debate and vote on each potential vulnerability, and only findings that reach a quorum go into the report.
